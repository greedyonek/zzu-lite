# ZZU_Lite

郑州大学学生日常服务安卓应用（非官方）。核心功能：**课程表**，附加：个人信息 / 一卡通余额 / 宿舍电费查询 / 校园网一键认证。

接口实现参考并复刻自朋友的开源项目 [ZZU.Py](https://github.com/Illustar0/ZZU.Py)（MIT），在此致谢。

> ⚠️ 本应用仅限郑州大学在校生个人使用，请勿用于任何违反校规或服务条款的场景。

## 功能

| 模块 | 说明 |
|---|---|
| 统一认证登录 | 账密 RSA 加密登录，支持短信 MFA 两步验证，token 过期自动续登（需记住密码） |
| 课表 | 周视图网格（7 天 × N 节），左右滑动切换周次，学期切换，课程详情，今日高亮，离线缓存 |
| 今日 | 今日课程时间线、一卡通余额、当前教学周 |
| 桌面小组件 | 今日课程卡片：周次、每节课时间地点，下一节高亮，点按进应用 |
| 空教室 | 按校区/楼栋/日期/节次查询空闲教室（占用数据实时） |
| 服务页 | 校园网一键认证（自动探测网关、运营商后缀选择）、宿舍电费查询（可改绑房间）、设置 |

> 网络说明：App 会把请求强制绑定到 Wi-Fi 网络（解决"校园 Wi-Fi 未认证时系统默认走流量导致教务不可达"的问题）。

## 技术栈

Kotlin + Jetpack Compose (Material 3) + OkHttp/Retrofit + kotlinx.serialization + DataStore + EncryptedSharedPreferences

- minSdk 26 / targetSdk 36
- 无第三方 SDK、无统计、无网络上传，凭据仅存本机加密存储

## 构建

```bash
# 需要本机 JDK 17 与 Android SDK（api 36.1 / build-tools 36.1.0）
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 真实接口集成测试（可选）

```bash
./gradlew test -Dzz.user=学号 -Dzz.pass=密码
# 若触发短信 MFA：将 6 位验证码写入 zzu_code.txt（测试进程轮询 3 分钟）
```

## 已知限制

- 仅支持本科教务（新系统），研究生教务未适配（与 ZZU.Py 一致）
- 成绩 / 考试安排等接口 ZZU.Py 源码中暂未提供，故本应用也未实现
- 校园网认证需连接校园网 WiFi 后使用（自动探测网关）
- 电费充值功能刻意未实现（涉及支付，风险自担）
- 电费查询依赖校园卡系统中的电费账户绑定：实测发现未绑定电费账户的账号会被服务端拒绝（`valid_error_1004`），应用会给出友好提示并支持级联选择改绑房间
